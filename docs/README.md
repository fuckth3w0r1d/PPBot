# 文档导航

PPBot 是通过 NapCatQQ 收发群聊消息的 C++ 机器人，提供文本命令、AI 对话和 B 站分享卡片处理。需求规格规定当前分支的目标行为，架构说明和开发与运行指南描述当前源码及运行边界。

## 阅读入口

| 文档 | 内容 |
| --- | --- |
| [需求规格](spec.md) | 目标使用场景、单聊天模型与独立判定模型的分工、回复触发、共享群上下文和验收要求 |
| [架构说明](map.md) | 当前源码的模块职责、消息路径、AI 状态与持久化、外部依赖 |
| [开发与运行指南](guides/development.md) | 构建与模拟验收、s0 部署、聊天及判定配置、NapCat 接入、数据目录和真实接入验证 |

接续开发时，先通过需求规格确定行为与验收边界，再从架构说明中的源码入口定位实现。聊天使用单主模型、独立判定服务和共享群时间线，普通插话概率默认 10%，可配置。需要在 s0 实测时，先按开发与运行指南核对判定服务配置、构建并更新 `qqbot` 二进制；首次搭建和旧数据保留方法也见该指南。根 [README](../README.md) 提供项目介绍和原项目环境记录，实际配置文件名、配置加载路径和运行限制见本目录的指南。

## 文档组织

`spec.md` 保存当前有效的目标需求与验收要求，`map.md` 保存已经实现的架构，`guides/` 保存独立操作指导。各 Git 分支沿用相同路径，文档随代码审查和合并。

任务计划、未实施方案、执行结果和审查记录保存在会话、Issue 或 PR 中。新增、移动或删除正式文档时，同步维护本页导航。
