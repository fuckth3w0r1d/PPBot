# 文档导航

PPBot 是通过 NapCatQQ 收发群聊消息的 C++ 机器人，提供文本命令、图文 LLM 对话、拍一拍回应和 B 站分享卡片处理。需求规格只记录待开发需求，已有功能、源码结构及运行边界见架构说明和开发与运行指南。

## 阅读入口

| 文档 | 内容 |
| --- | --- |
| [需求规格](spec.md) | 尚未实现的需求及其验收要求 |
| [架构说明](map.md) | 系统概览、模块职责、关键协作流程、运行与部署关系 |
| [开发与运行指南](guides/development.md) | 构建与模拟验收、s0 部署、聊天、判定与 embedding 配置、NapCat 接入、SQLite 迁移与数据清理、停机和真实接入验证 |

开发新功能时，先通过需求规格确认待开发行为与验收要求，再从架构说明中的源码入口定位已有机制。了解现有功能时，阅读架构说明和开发与运行指南。需要在 s0 实测时，先按开发与运行指南核对配置、构建并更新 `qqbot` 二进制；首次搭建和数据保留方法也见该指南。根 [README](../README.md) 提供项目介绍、主要功能和构建入口，实际配置文件名、配置加载路径和运行限制见本目录的指南。

## 文档组织

`spec.md` 保存当前开发需求及验收要求，对应分支开发完成后清空并恢复模板；`map.md` 保存已经实现的架构，`guides/` 保存独立操作指导。各 Git 分支沿用相同路径，文档随代码审查和合并。

开发变更历史由 Git 保存，任务计划、未实施方案、执行结果和审查记录保存在会话、Issue 或 PR 中。新增、移动或删除正式文档时，同步维护本页导航。
